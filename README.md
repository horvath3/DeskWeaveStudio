# 🚀 DeskWeave Studio
### Turn Websites into Beautiful Windows Apps.

**DeskWeave Studio** is a modern Windows desktop application builder that transforms your favorite websites and web applications into standalone Windows programs — without requiring any programming knowledge.

Powered by a streamlined workflow and a premium Midnight Pro interface, DeskWeave Studio makes creating desktop applications simple, fast, and accessible to everyone.

## ✨ Key Features

### 🌐 Website to Desktop App
Convert websites into Windows applications by simply entering a URL. Customize your application and generate a ready-to-use executable.

### 🎨 Visual App Designer
Personalize your applications with a visual editor:
- Custom application names and icons
- Window size and appearance settings
- Customizable title bars
- Splash screens and startup options
- Live application preview

### ⚡ Smart Website Detection
Automatically detect available website information, including titles, favicons, and metadata, to speed up the creation process.

### 🖥️ Windows EXE Builder
Export your projects as:
- **Portable EXE** – Launch your application without installing DeskWeave Studio.
- **Windows Installer** – Create a traditional installer for easy distribution.

### 🔧 Automated Build Center
Follow the application creation process through a modern, animated interface featuring progress indicators, status updates, and detailed build information.

### 📁 Project Management
Save, organize, edit, and rebuild your projects from a dedicated project library.

### 🌙 Midnight Pro Interface
Enjoy a modern desktop experience featuring:
- Dark and light themes
- Smooth animations
- Elegant navigation
- Clean, intuitive controls
- Hungarian and English language support

## 🚀 How It Works

1. **Enter your website URL.**
2. **Customize your application** using the Visual App Designer.
3. **Choose your export format** – Portable EXE or Windows Installer.
4. **Create your application** using the automated Build Center.
5. **Launch or share your new Windows application!**

No coding required.

## 💻 System Requirements

- Windows 10 or Windows 11 (64-bit)
- Microsoft Edge WebView2 Runtime for WebView2-based applications
- Internet connection for websites requiring online access

## 📦 Installation

Download the latest available version from the GitHub Releases section.

Choose the installer or portable version, launch DeskWeave Studio, and start creating your applications.
